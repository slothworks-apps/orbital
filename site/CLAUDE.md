# The Orbital website

`site/` is the public website at `orbital.slothworks.io`: a static page
that says what Orbital is, shows it working, and links to the Mac
download. It is Astro, with React used only inside the demos. See
`docs/superpowers/specs/2026-10-08-landing-site-design.md` for what it
does and `docs/decisions/the-landing-site-is-astro-in-this-repository.md`
for why it is a workspace here rather than its own repository.

## Copy and layout come from the design canvas

The page's layout, ink, type and copy live in the design canvas, which is
maintained outside this repository. This workspace does not
restate them, and nothing here checks them: fidelity against the canvas
is verified by the main session during the work, by eye, not by a test.
A test that pins a pixel size or a copy string only breaks the next time
the canvas changes.

## The demos reach into web/src

Each demo (`site/demo/`) is a small app of its own that renders the
app's real components from `web/src` on demo data, through a fake
`fetch` and a fake WebSocket rather than changed components. So a change
to a component in `web/src` can change what the website shows, and
CI builds and typechecks the site for such a change (`site` job in
`.github/workflows/ci.yml`), the same way it would for a change inside
`site/` itself.

## The privacy text is the maintainer's

`site/content/privacy.md` is not placeholder copy: it is drafted from
the code and checked claim by claim. Re-check it whenever the relay,
a push notification or how a part of Orbital handles data changes —
the page has to stay true to what the code does, not to what it did
when the text was written.

## No analytics, no third-party requests

The site sets no cookies and makes no request to a third party: no
analytics, no tracking script, no Google Fonts. Fonts are self-hosted
from the site's own assets. This is also what the privacy text promises
("No analytics, in the app or on this site"), so it must stay true of
whatever is added here.

## Testers vs. public

`PHONE_RELEASE` in `site/src/site.ts` is the one build-time switch
between the phone apps being invite-only (`'testers'`) and public
(`'public'`). It changes the texts and buttons the canvas switches with
its `release` tweak. Going public is this one line plus the store URLs.

## The demo images are screenshots, committed

The posters and narrow-screen images under `site/public/demo-images/` are not
drawn by hand: a script drives the built demos in a headless browser and
screenshots them. The build does not take screenshots itself — the
images are committed to the repository and only regenerated by running
that script when the app's look changes. It lives in `site/scripts/`
once it is added.

## Running it

```bash
npm run build:demo -w @orbital/site   # once, builds the demo pages the dev server embeds
npm run dev -w @orbital/site
```

## Versions

None. The site has no version and no changelog; it deploys straight from
`main` (`.github/workflows/site-deploy.yml`, runbook
`docs/ops/deploy-the-site.md`).
