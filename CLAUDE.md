## Documentation

Every markdown file under `docs/` carries atlas frontmatter, and
`docs/CLAUDE.md` is the full rule: the fields, the types, the statuses
and the directory each type lives in. Read it before you write, move or rename
a document.

```bash
atlas validate    # run this before you commit
```
