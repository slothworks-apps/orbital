# Orbital is MIT licensed

The repository goes public, and without a license nobody may legally use or
change the code. It is licensed under MIT, copyright SlothWorks s.r.o.

Apache 2.0 was ruled out: it adds an explicit patent grant that a local
desktop tool has no use for, at the cost of a much longer text. AGPL-3.0 was
ruled out because it would keep companies from adopting a tool whose point
is to be picked up and changed. A source-available license (PolyForm
Noncommercial and the like) was ruled out because Orbital is not meant to be
sold, so restricting commercial use protects nothing.
