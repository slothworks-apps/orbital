# A long-press on a phone list row opens the session menu

The desktop gets a right-click menu on planets and sidebar rows
(`2026-10-24-session-context-menu-design`). The phone's counterpart would be
a long-press on a session row in the list opening the ⋯ sheet
(`SessionMenuSheet`) for that session, without opening it first. The sheet
and its rules already exist; only the gesture is missing.

Left out of the desktop change because the phone has no map and the sheet
is one tap away once a session is open.
