# Edit a running harness's steps and dependencies from the phone

The phone can apply or discard what the agent proposes and approve gates,
but it cannot edit the harness itself: a per-step "depends on" editor does
not fit a phone screen, so it was left out of
[[2026-10-06-harness-graph-and-proposals-design]].

A phone-sized version could be narrower: add a step after a chosen one,
remove a pending step, or tell the agent in words what to change and let it
propose (which already works). Worth doing once the desktop editor has
settled.
