# One tag order for every Mac in a group

Each Mac keeps its own tag order today
([[2026-10-25-tag-toggles-and-order-design]]). A phone paired with several
Macs shows their tags one Mac after another, each in its own order. A tag
with the same name on two Macs takes the place it has on the Mac read first.

Claude Design's `Feature - Tag chips` drew one order shared across the
group. It is one setting, set by a drop on any device. That rests on the
Shared settings proposal, which is not built yet. When Shared settings
lands, the tag order is a natural first setting for it: a drop on one Mac
writes the order every member and the phone follow.
