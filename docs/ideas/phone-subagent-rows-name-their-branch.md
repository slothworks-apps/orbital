# The phone's subagent rows name the branch they work on

The desktop header counts the other trees that running subagents work in
and lists them on hover ([[2026-10-07-live-working-tree-design]]). The phone
leaves that out because its header line has no room and no hover.

If the phone needs this, put it in the subagent list rather than the
header: a subagent whose tree differs from the session's shows that tree's
branch on its row. The data is already in the session shape (`otherTrees`).

Archived on 2026-10-07: the phone now gets the same count and list of trees
as the desktop ([[2026-10-07-live-working-tree-design]] § The phone), so
this alternative is not needed.
